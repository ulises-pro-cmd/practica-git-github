## Proyecto de la cátedra

El proyecto consiste en el desarrollo de una **Tienda Online**, una plataforma web destinada a permitir a los usuarios consultar productos y realizar compras de manera sencilla y organizada. El sistema busca facilitar la gestión de los productos, los usuarios y las operaciones de compra, ofreciendo una solución digital para una tienda.
